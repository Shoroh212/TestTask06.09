# ТЗ





Данный проект представляет собой игровой прототип

Основной целью проекта была реализация ключевых игровых механик и создание полностью функционального игрового процесса.

При разработке основной акцент был сделан на быструю реализацию и проверку игровых механик, а не на построение сложной архитектуры.

## Архитектура



Основной причиной является небольшой масштаб проекта. Добавление большого количества абстракций и архитектурных слоёв увеличило бы сложность разработки, но не дало бы существенных преимуществ в рамках текущей задачи.

При дальнейшем масштабировании проекта код можно было бы переработать и разделить на более независимые системы с чётким разделением ответственности.

## Подход к разработке

Основными приоритетами при разработке были:

- Быстрое прототипирование
- Реализация основных игровых механик
- Читаемый и понятный код
- Использование компонентного подхода Unity
- Плавные анимации с помощью DOTween
- Отсутствие избыточных абстракций


Проект демонстрирует навыки разработки игровых механик на **Unity и C#**, работу с компонентной системой Unity и использование сторонних инструментов, таких как **DOTween**.

Архитектура проекта намеренно оставлена простой с учётом его масштаба, при этом код может быть дополнительно переработан и масштабирован при дальнейшем развитии проекта.
